    Carregar um mapa

    Cole o texto do mapa ou escolha um arquivo .txt. O servidor roda o código Python do grupo (leitura do mapa, grafo de estados e os três algoritmos) e o mapa entra no player como Personalizado.

    Nenhum arquivo escolhido

    Este é o arquivo estático gerado por src/viz.py: não há servidor para resolver um mapa novo. Para rodar um mapa surpresa, use a linha de comando do projeto:

    python -m src.cli --mapa arquivo.txt --interactive

    Como funciona

    A masmorra vira um grafo dirigido. Cada vértice é um estado: a casa onde o aluno está, as chaves que ele já tem e os bônus que já usou. Cada arco é um passo para uma casa vizinha e custa o terreno de destino. O objetivo é o baú (a saída, G).

    Por isso o mesmo corredor aparece várias vezes no grafo. Passar por ali sem chave ou com a chave a são estados diferentes, e uma porta só tem arco de entrada nas camadas que têm a chave dela.

    As esteiras só deixam sair na direção da seta. A fonte devolve 2 de custo toda vez que o aluno pisa nela, e é assim que aparece um ciclo negativo.
